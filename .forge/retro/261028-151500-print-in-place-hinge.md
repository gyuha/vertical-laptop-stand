## 배운 점

- 다음에는 축을 세워 출력하는 회전 대칭 경첩을 grilling(계획을 질문으로 검증하는 단계)할 때 원뿔 각도만 묻지 않는다. 위 마디가 자기 몸체와 몇 도만큼 연결되는지, 즉 첫 층이 허공에서 시작하는 범위부터 측정하고 질문한다. 이번에는 실행 중에야 302° 비지지가 드러났다.
- 다음에는 "N° 초과 면적 0" 같은 출력성 완료 조건을 STL 법선으로만 정의하지 않는다. 정확한 판정은 CAD 면으로 하고, 메시는 근사 허용을 명시한다. 그리고 면 기울기 검사가 잡지 못하는 "지지 연속성"은 별도 수치로 정의한다.
- 다음에는 공용 스크립트(`slice_calibration.py`)를 수정한 뒤 기존 대상을 재실행해 회귀 확인을 할 때, 추적 중인 결과 파일이 처리 시간 값만으로도 바뀐다는 점을 감안한다. 확인 후 되돌리거나, 시간 필드를 비교에서 제외한다.
- 유지할 점: 직렬 의존 작업은 워크플로 없이 직접 실행했고, 기존 산출물이 git 변경 없이 보존되는지 매번 확인했다.
