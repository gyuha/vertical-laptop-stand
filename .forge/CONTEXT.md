# 랩탑 세로 스탠드

사용자가 설명한 거치 동작을 기준으로 한 프로젝트 용어입니다.

## 용어

**양끝 분리 연결부**:
앞뒤 폭120mm의 양끝에 각각 하나씩 배치하는 짧은 연결 구조입니다. 사용자가 말한 ‘좌측끝·우측끝’은 이 폭 방향의 두 끝이며, 가운데를 하나의 긴 원통으로 잇지 않고 중간 구간을 비웁니다.

**단축 출력 봉**:
양끝 분리 연결부에 사용하는 짧은 봉입니다. 기존 봉의 형태는 유지하면서 새 연결 구조에 맞춰 길이를 조정합니다.

**안쪽 열린 클립**:
양끝의 짧은 봉을 고정하며 가운데 빈 공간을 향해 놓이는 열린 걸쇠입니다. 봉은 바깥쪽에서 안쪽으로 넣고, 바깥에는 기존의 둥근 봉 머리가 보입니다.

**하중 작동식 오므림**:
노트북을 올리면 그 무게로 양쪽 받침이 안으로 모이는 동작입니다.

**벌림 복원용 고무줄**:
노트북이 없을 때 양쪽 받침을 벌어진 상태로 되돌리는 하단 고무줄입니다.

**하단 벌림 제한 턱**:
경첩 결합부 아래에서 서로 맞닿아 최대 벌림을 제한하는 좌우 일체형 턱입니다. 오므라들 때는 서로 떨어집니다.

**안쪽 고무줄 걸이**:
전면 하단 가로부의 뒷면에서 스탠드 안쪽을 향하는 수평 걸이입니다. 별도의 아래 선반에 세우는 걸이를 뜻하지 않습니다.

2026-10-28 사용자 캡슐형 보강 요청을 반영해 가로14×세로6×두께1.4mm 머리와12×4mm 목으로 변경했습니다. 머리 테두리는R0.35mm이며 중심은축아래11.9mm입니다. 넓어진 걸이와 고무줄의 경첩 간섭을 피하기 위해 이전보다1.1mm 내렸습니다. 후속 지적에서 목 절반이 받침 밖으로 떠 있던 문제를 확인해 받침을15×7×두께4mm의 둥근 캡슐 윤곽으로 확장했습니다. 현재 목 전체44.57mm²와 머리의 투영 윤곽이 받침 위에 놓입니다. 단일 솔리드나 이전보다 큰 연결 면적만으로 전체 지지를 가정하지 말고 목 단면과 받침 사이의 미지지 부분이 없는지 차집합으로 검사합니다. 이는 실물 강도 시험 결과가 아닙니다. 이 변경은 좌우 두 몸체를 재출력해야 하며 축·고정 캡·끼움 시험판은 유지합니다.

추가 외형 요청에 따라 현재 받침은 별도 캡슐을 붙인 윤곽 대신 다리 사선에서 하단 평면으로 접선이 이어지는 연속 곡선 윤곽입니다. 앞 모서리는 합친 뒤R1mm, 목 접합부는R0.35mm로 다듬으며 하단 벌림 턱의 평평한20mm² 접촉면은 유지합니다. 목 전체 지지와 고무줄 공간도 유지합니다.

**조립 부품 모음**:
현재 양끝 분리 설계의 기본 전체 판STL·3MF·FCStd·STEP에는 좌우 몸체2개·단축 출력 봉2개·안쪽 열린 클립2개, 총6개만 포함합니다. 별도 소형 시험판은 앞쪽 경첩 시험편2개·봉1개·클립1개이며 기본 모음에서 제외합니다. 이전v14의 모음은 몸체2개·주 축·고정 캡의4개 구성으로 보존하며, 끼움 시험 링3개를 제외한다는 사용자 요청도 유지합니다. 근거는 `exports/snap-retainer/manifest.json`과 `docs/evidence/snap-retainer/geometry-report.json`입니다.

**경첩 끝면 간격**:
서로 맞물리는 경첩 마디의 앞뒤 끝면 사이 거리입니다. 축 구멍의 지름 여유와 구분합니다. 초기0.3mm는 서포트 면 거칠기로 좁았고, 이후1.0mm는 축의 노출이 커 보여 줄여 달라는 피드백을 받아 **앞뒤 각각0.6mm**로 정했습니다. 이전v14에서는 오른쪽 중앙 마디를 v13보다 양끝0.4mm씩 늘려102.8mm로 만들었습니다. 현재 양끝 분리 설계에서도 두 끝면 간격0.6mm를 유지하며, 중앙 원통을 제거해 연결부는 각각20mm이고 봉 끝 사이 실제 빈 구간은72.8mm입니다. 새 봉은 총길이25.6mm로2개 사용합니다. 열린 클립은 중앙 혀 높이1.6mm·두께1.8mm이며 슬롯을 세로로 맞춘 뒤 안쪽 아래에서 위로 끼웁니다. 근거는 새 형상 보고서의 `hinge_end_face_gaps_mm`, `central_clear_length_mm`, `insertion_paths`입니다. 실물 조립·탄성 복원 성능은 미확인입니다.
