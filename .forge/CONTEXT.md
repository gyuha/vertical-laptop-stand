# 랩탑 세로 스탠드

사용자가 설명한 거치 동작을 기준으로 한 프로젝트 용어입니다.

## 용어

**하중 작동식 오므림**:
노트북을 올리면 그 무게로 양쪽 받침이 안으로 모이는 동작입니다.

**벌림 복원용 고무줄**:
노트북이 없을 때 양쪽 받침을 벌어진 상태로 되돌리는 하단 고무줄입니다.

**하단 벌림 제한 턱**:
경첩 결합부 아래에서 서로 맞닿아 최대 벌림을 제한하는 좌우 일체형 턱입니다. 오므라들 때는 서로 떨어집니다.

**안쪽 고무줄 걸이**:
전면 하단 가로부의 뒷면에서 스탠드 안쪽을 향하는 수평 걸이입니다. 별도의 아래 선반에 세우는 걸이를 뜻하지 않습니다.
