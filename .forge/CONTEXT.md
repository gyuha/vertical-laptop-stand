# 랩탑 세로 스탠드

사용자가 설명한 거치 동작을 기준으로 한 프로젝트 용어입니다.

## 용어

**하중 작동식 오므림**:
노트북을 올리면 그 무게로 양쪽 받침이 안으로 모이는 동작입니다.

**벌림 복원용 고무줄**:
노트북이 없을 때 양쪽 받침을 벌어진 상태로 되돌리는 하단 고무줄입니다.

**하단 벌림 제한 턱**:
경첩 결합부 아래에서 서로 맞닿아 최대 벌림을 제한하는 좌우 일체형 턱입니다. 오므라들 때는 서로 떨어집니다.

**안쪽 고무줄 걸이**:
전면 하단 가로부의 뒷면에서 스탠드 안쪽을 향하는 수평 걸이입니다. 별도의 아래 선반에 세우는 걸이를 뜻하지 않습니다.

2026-10-28 사용자 캡슐형 보강 요청을 반영해 가로14×세로6×두께1.4mm 머리와12×4mm 목으로 변경했습니다. 머리 테두리는R0.35mm이며 중심은축아래11.9mm입니다. 넓어진 걸이와 고무줄의 경첩 간섭을 피하기 위해 이전보다1.1mm 내렸습니다. 후속 지적에서 목 절반이 받침 밖으로 떠 있던 문제를 확인해 받침을15×7×두께4mm의 둥근 캡슐 윤곽으로 확장했습니다. 현재 목 전체44.57mm²와 머리의 투영 윤곽이 받침 위에 놓입니다. 단일 솔리드나 이전보다 큰 연결 면적만으로 전체 지지를 가정하지 말고 목 단면과 받침 사이의 미지지 부분이 없는지 차집합으로 검사합니다. 이는 실물 강도 시험 결과가 아닙니다. 이 변경은 좌우 두 몸체를 재출력해야 하며 축·고정 캡·끼움 시험판은 유지합니다.

추가 외형 요청에 따라 현재 받침은 별도 캡슐을 붙인 윤곽 대신 다리 사선에서 하단 평면으로 접선이 이어지는 연속 곡선 윤곽입니다. 앞 모서리는 합친 뒤R1mm, 목 접합부는R0.35mm로 다듬으며 하단 벌림 턱의 평평한20mm² 접촉면은 유지합니다. 목 전체 지지와 고무줄 공간도 유지합니다.

**조립 부품 모음**:
사용자 요청으로 기본 전체 판STL·3MF·FCStd·STEP에는 좌우 몸체·주 축·고정 캡4개만 포함합니다. 끼움 시험 링3개는 조립에 쓰지 않으며 이 모음에서 제외합니다. 시험 링 개별 파일과 별도fit-plate는 선택 사항으로 유지합니다.

**경첩 끝면 간격**:
서로 맞물리는 경첩 마디의 앞뒤 끝면 사이 거리입니다. 축 구멍의 지름 여유와 구분합니다. 2026-10-28 사용자 출력 피드백에서 서포트 면 거칠기로 간격 부족이 보고되어, 중앙 정렬 기준 앞뒤 각각0.3→1.0mm로 늘렸습니다. 오른쪽 중앙 마디만 줄여 기존 왼쪽 몸체·축·고정 캡을 유지합니다. 수정본 실물 조립·복원 성능은 재확인이 필요합니다.
