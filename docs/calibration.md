# 폭120mm PLA 설계 시제품

이 묶음은 사용자 표시 방향인 **지지벽의 앞뒤 폭을120mm(12cm)**로 맞춘 PLA 설계 시제품입니다. 경첩과 주 축 길이, 펠트 자리도 같은 폭에 맞췄습니다. 실물 조립·복원·안정성은 아직 확인하지 않았으며, 축 끼움과 동작 확인 결과를 후속 설계와 PETG 제작에 반영합니다.

현재 수정본은 **위로 돌출된 회전 제한 암·곡선 홈·작은 핀을 제거**했습니다. 경첩 축 아래의 좌우 일체형 턱이 맞닿아 최대 벌림만 제한합니다. 닫힐 때는 턱이 서로 떨어지고, 노트북과 펠트의 접촉으로 거치 폭이 정해지는 구상입니다.

고무줄 걸이는 **표시한 전면 하단 가로부의 뒷면에서 스탠드 안쪽을 향하는 수평 걸이**입니다. 좌우 하나씩 있으며, 가로부 앞쪽으로 나오던 방향을 반대로 돌린 구조입니다. 별도의 아래 선반과 수직 걸이는 제거했습니다.

걸이 양끝에서 넓게 퍼지던 뾰족한 삼각형 보강부를 제거하고, 네모난 수직 끝선을 **주변 다리에 이어지는 사선**으로 바꿨습니다. 위쪽은 연결부로 자연스럽게 넓어지고 아래쪽은 걸이 가까이 모이는 윤곽입니다. 사선 끝과 안쪽 연결 전환부는 반지름1mm로 둥글게 마감하며, 하단 벌림 턱은 유지했습니다. 실제 강도와 안정성은 출력 후 확인합니다.

지지벽과 바닥 발의 노출된 바깥 테두리·앞뒤 끝 모서리에는 **R1mm 필렛**을 적용했습니다. 앞쪽 축 머리의 원형 테두리도 R0.35mm로 다듬어 고정 캡과 마감이 어울리도록 했습니다. 축 구멍과 맞물림 면, 펠트가 앉는 평면, 바닥 접촉 기준점은 유지해 치수와 운동 조건을 보존했습니다.

## 경첩 마디 간격 조정

경첩 마디 끝면 간격은 현재 **앞뒤 각각0.6mm**입니다. 초기0.3mm는 서포트 면 거칠기로 좁았고, 이후1.0mm는 축의 노출이 커 보인다는 피드백을 받아 **1.0→0.6mm로40% 축소**했습니다. 오른쪽 중앙 마디를 양끝에서0.4mm씩 늘려 길이를102.0→102.8mm로 조정했습니다. 0.6mm는 중앙 정렬 상태에서 각 끝면 사이 거리이며 축 구멍의 지름 여유0.4mm와 별개입니다.

**v13의 캡슐형 걸이·연속 받침 모델을 사용한다면 오른쪽 몸체만 재출력**하면 됩니다. 왼쪽 몸체·주 축·원형 고정 캡과 별도 끼움 시험판은 변경하지 않았습니다. 이전 원형 걸이 모델에서 캡슐형 걸이까지 적용하려면 좌우 두 몸체를 재출력합니다. 큰 서포트 잔여물을 제거한 뒤 실제 끼움·회전·앞뒤 흔들림을 확인합니다. 설정값은 `cad/parameters.json`의 `axial_clearance`입니다.

## 캡슐형 고무줄 걸이

작은 원형 머리와 목을 모두 가로로 긴 캡슐형으로 바꿨습니다. 머리는14×6mm, 두께1.4mm이며 가장자리는R0.35mm입니다. 목은12×4mm, 돌출 길이3.2mm로 넓혔습니다.

목 아래쪽이 기존 받침 밖으로 떠 있던 문제를 수정한 뒤, 받침이 따로 붙은 캡슐처럼 보이던 윤곽도 정리했습니다. **다리의 사선에서 하단 받침으로 이어지는 하나의 곡선 윤곽**이며 두께는4mm입니다. 다리 기울기와 하단 평면에 접하는 곡선으로 오목한 턱을 채우고, 앞쪽 노출 모서리는R1mm로 마감했습니다. 목과 뒤쪽 일부 모서리는R0.35mm입니다. 받침은Y=0~4mm에 있으며 목은그뒤Y=4~7.2mm에 연결됩니다. 고무줄을 거는 목 공간은 유지합니다.

실제 몸체와 만나는 목 단면은 **20.25→44.57mm²**로 늘었습니다. 목 전체와 머리 투영 윤곽의 아래에 받침이 있는지 솔리드 차집합으로 검사합니다. 이 값은 연결 면적이며 실물 강도 시험 결과를 뜻하지 않습니다.

걸이 중심은 축 아래11.9mm로, 이전보다1.1mm 내려갔습니다. 넓어진 목을 감싼 고무줄이 경첩과 닿지 않도록 조정한 위치입니다. 고무줄은 두 캡슐형 목 전체를 감싸야 하며, 그림은 굵기1mm의 예시 경로입니다. 이전 원형 걸이와 필요한 둘레가 달라 장력을 다시 조절합니다.

## 선택 사항: 끼움 시험판

`exports/calibration/fit-plate.stl`은 처음 출력하거나 재료를 바꿀 때 사용하는 별도 시험판입니다. 6mm 축, 축 고정 캡, 구멍 여유가 다른 시험 링 세 개가 포함됩니다. **링은 조립에 쓰지 않으며 이미 끼움을 확인했다면 출력하지 않아도 됩니다.** 구멍 여유는 반지름 차이가 아니라 **지름 차이**입니다.

| 링 표시 | 파일 | 구멍 지름 | 6mm 축과의 지름 여유 |
|---|---|---|---|
| 점 1개 | fit-20.stl | 6.2mm | 0.2mm |
| 점 2개 | fit-40.stl | 6.4mm | 0.4mm |
| 점 3개 | fit-60.stl | 6.6mm | 0.6mm |

축이 손으로 들어가고 부드럽게 회전하며 흔들림이 지나치지 않은 링을 찾습니다. 링에는 점 표시가 위로 돌출되어 있습니다. 동작 시험편은 우선 **점 2개에 해당하는 6.4mm 구멍**으로 생성했습니다. 여기에 축이 들어가지 않으면 전체 동작 시험편을 바로 출력하지 말고 결과를 알려 주세요.

## 동작 시험편의 부품

| 부품 | 파일 | 수량 |
|---|---|---|
| 왼쪽 지지대 | mechanism-left.stl | 1 |
| 오른쪽 지지대 | mechanism-right.stl | 1 |
| 주 경첩 축, 지름 6mm | axle-6mm.stl | 1 |
| 원형 고정 캡 — 안쪽 고정 키 일체형 | axle-key.stl | 1 |
| 일반 사무용 고무줄 | 사용자가 준비 | 1개부터 조정 |
| 약 1mm 접착식 펠트 | 사용자가 준비 | 114×30mm 2장 |

`calibration-plate.stl`은 **좌우 지지대·주 축·고정 캡만 포함한4개 조립 부품 모음**입니다. 시험 링 세 개는 이 모음에서 제외했습니다. FreeCAD 출력 배치와 STEP, 전체 판3MF도4개 부품입니다. 좌우 지지대 각각의 단면 폭은 약61mm, 높이는82mm, 사용자 지정 앞뒤 폭은정확히120mm입니다. 두 지지대를 펼친 상태의 좌우 바닥 전체 폭은110mm입니다. 주 축의 지지 길이는120mm이며 머리와 고정 부분을 포함한 총길이는126.5mm입니다. 이전32mm 시험편의 축은 길이가 달라 호환되지 않습니다.

## 출력 설정과 방향

- 기준 프린터: Bambu Lab X1C, **기본 0.4mm 노즐을 사용한다는 가정**입니다. 교체한 노즐이면 슬라이서에서 맞는 프로필을 선택합니다.
- 시제품 재료: PLA. 실제 보유 PLA에 맞는 필라멘트 프로필을 선택합니다. 확인용 슬라이싱은 Generic PLA와 Textured PEI Plate를 사용했습니다. 다른 베드를 쓰면 해당 베드로 바꿉니다.
- 시작값: 레이어0.20mm, 벽6겹, 채움25%. 재현 스크립트는 설치된 Bambu Studio의 Strength 프로필을 기반으로 합니다.
- 링과 축은 **구멍/축 방향이 수직**, 원형 고정 캡은 매끈한 바깥 원형 면이 베드에 닿게 합니다. STL에는 이 방향이 반영되어 있습니다.
- 지지대는 **평평한 전면(축 머리가 보이는 쪽)이 아래**입니다. 지지대와 고정 캡 모두 일반 자동 서포트, 빌드플레이트 전용 해제로 확인합니다. 특히 캡 안의 키 아래 서포트를 제거하고 안쪽 통로를 확인합니다. 축 구멍을 무리하게 깎아 공차 차이를 지우지 않습니다.
- 확인용 배치는 브림3mm를 사용합니다. Bambu Studio에서 슬라이스한 뒤 첫 층과 축의 브림을 확인합니다.

확인용 프로젝트는 `sliced-fit/fit-x1c-pla.3mf`, `sliced-mechanism/mechanism-x1c-pla.3mf`입니다. 후자는 시험 링을 제외한4개 조립 부품 판입니다. 기계 프로필의 상속과 시작 코드를 펼쳐 **실제 필라멘트 밀도 및 X1C 시작 코드가 포함되는지** 확인했습니다. 최초의 미완성 프로필로 만든 `fit-check.3mf`는 배포하지 않습니다.

현재 수정본의 별도 끼움 시험판 예측은 **약1시간12분·10.9g**, 조립용4개 부품 판은 **약5시간53분·181.2g**입니다. 경첩 끝면 간격0.6mm를 반영해 전체 판을 재슬라이싱했으며, 형상이 동일한 끼움 시험판은 기존 결과를 유지했습니다. 상세 값은 `sliced-fit/result.json`, `sliced-mechanism/result.json`에 기록했습니다. 실제 출력 시간과 소비량은 달라질 수 있습니다.

슬라이싱은 파일 생성만 수행했으며 **프린터에 전송하거나 출력하지 않았습니다**. 실제 출력 전에는 보유 PLA·베드·프린터 설정을 확인해 프로젝트를 다시 슬라이스하는 편이 좋습니다. 슬라이서의 시간과 소비량은 예측값입니다.

## 조립

1. 서포트와 브림을 제거하고 축 구멍, 마디 간격, 하단 턱의 맞닿는 면과 안쪽 걸이 목 부분을 확인합니다.
2. 좌우를 결합하기 전에 가로부 뒷면의 안쪽 걸이 한 쌍에 고무줄을 먼저 걸어 둡니다. 고무줄이 캡슐형 머리와 가로부 사이의 넓은 목 전체를 감싸도록 합니다. 좌우 경첩 마디를 서로 맞물린 뒤, 완전히 벌어진 위치에서 경첩 아래의 두 턱이 맞닿는지 확인합니다.
3. 지름6mm 주 축을 앞에서 뒤로 넣습니다. 큰 머리가 앞쪽 경첩 면에 닿으면 반대쪽 축 끝에 원형 고정 캡을 끼웁니다. 캡의 평평한 원형 면이 바깥을 향하고, 옆면 개구부가 축 쪽을 향하도록 놓은 뒤 **옆에서 밀어 넣습니다**. 안쪽에 일체형 키가 있어 기존 축의 가로 구멍을 통과합니다. 부품 수는 늘지 않았습니다.
4. 밖에서는 지름10mm의 둥근 마감 캡만 보이고 고정 키는 캡 윤곽 안에 숨습니다. 캡의 앞쪽 가장자리는 경첩 뒷면에서0.25mm 떨어져 있습니다. 분해할 때는 캡을 옆으로 밀어 빼고 축을 뽑습니다. **실제 캡의 끼움·유지력은 아직 미검증**이므로 쉽게 빠지거나 과한 힘이 필요하면 상태를 기록합니다.
5. 좌우 안쪽의 얕은 홈에 약1mm 펠트를 붙입니다. 홈 깊이는0.4mm라 펠트가 약0.6mm씩 돌출되는 구상입니다. 위쪽 끝까지 보호하도록 114×30mm로 자릅니다. 접착층 포함 실제 두께는 달라질 수 있습니다.
6. 고무줄이 가로부 뒤쪽에서 좌우 걸이를 연결하는지 확인합니다. 캡슐형 머리가 고무줄의 이탈을 막고 고무줄은 축 아래의 내부 공간을 가로지릅니다. 다시 걸기 어려우면 축을 빼고 좌우를 나눠 교체합니다. 그림의 고무줄은 배치 설명용입니다.

## 고무줄 조절과 동작 확인

걸이는 중심에서 좌우10mm, 축보다11.9mm 아래의 한 쌍입니다. 전면 가로부의 뒷면(Y=4mm)에서 안쪽(+Y)을 향해 돌출되며 머리 끝은Y=8.6mm입니다. 고무줄 규격과 늘어나는 힘을 측정하지 않았으므로 고정된 길이·개수·감는 횟수를 지정하지 않습니다.

1. 고무줄 없이 손으로 중앙의 단단한 받침을 누르고 놓으며 걸림 없이 움직이는지 확인합니다. 양쪽 벽이 모일 때 중앙이 내려가고 하단의 두 턱이 떨어져야 합니다. 다시 벌리면 턱끼리 맞닿아 벌림을 제한해야 합니다. 닫힘 전용 멈춤 부품은 없습니다.
2. 고무줄을 한 쌍에 걸고 길이와 감는 횟수로 장력을 조절합니다. 여러 번 감을 경우 걸이 목에 고무줄이 들어갈 여유가 있는지 확인합니다.
3. 중앙을 눌렀다 놓았을 때 벌어진 상태로 돌아오는 **가장 약한 장력부터** 시험합니다. 장력이 지나치면 노트북 무게로 닫히지 않습니다.
4. 하중은 **단단한 중앙 받침 두 곳**에 전달합니다. 먼저 모사판으로 동작을 확인한 뒤 실제 맥북의 패드 접촉과 흔들림을 확인합니다. 노트북 두께와 패드가 닫히는 폭을 정하므로 과하게 누르지 말고 패드 접촉을 확인합니다. 폭120mm 확장만으로 실제 하중 성능이 입증된 것은 아닙니다.
5. 눌렀을 때 양쪽이 모이고 놓으면 벌어지는지, 걸이·고무줄이 바닥에 끼지 않는지, 축·고정 캡이 밀려 나오지 않는지 확인합니다. 책상과 발 사이 마찰에 따라서도 동작이 달라질 수 있습니다.

## 디지털 검사에서 확인한 범위

`python3 scripts/check_geometry.py --target calibration`은 실제 STL과 FreeCAD 솔리드를 읽습니다. 결과는 `docs/evidence/geometry-report.json`에 저장합니다.

- 개별 부품7개와 배치 STL2개: 닫힌 메시, 면 방향, 퇴화 면, 연결 성분, 양의 체적, 자기 교차를 검사합니다.
- 표시했던 삼각형 날개의 위치에 재료가 남아 있지 않은지 확인하고, 걸이·몸체가 각각 끊어지지 않은 단일 솔리드로 이어지는지 검사합니다.
- 실제 솔리드에 R1mm의 긴 바깥 필렛 면이 생성되어 있는지 확인합니다. 다리와 받침 사이 연결 곡선 두 개 및 접선 방향도 검사합니다. 이전 오목한 턱 위치에 재료가 연결되어 있는지 확인합니다.
- 좌우 실제 CAD 솔리드의 앞뒤 폭이 각각120mm인지 검사합니다. 경첩의 앞뒤 마디와 주 축·고정 쐐기 위치도 같은 폭을 사용합니다.
- 실제 경첩 마디의 앞뒤 환형 끝면 사이 거리를 각각 측정해0.6mm인지 확인합니다.
- 캡슐형 목의 실제 단면 치수12×4mm와 단면적44.57mm², 머리14×6×1.4mm를 측정합니다. 실제 몸체 연결 면적도44.57mm²로 목 전체가 붙어 있으며, 머리 투영 윤곽까지 받침이 덮는지 검사합니다. 받침의 바닥 여유도33자세에서 검사하며 최소 약1.05mm입니다. 연결 면적을 물리적 강도 배수로 해석하지 않습니다.
- 0~8.2도 사이33개 자세: 좌우 몸체의 체적 간섭, 바닥 침범, 축 통과, 하중 받침에 대한 모사판의 접촉을 검사합니다. 8.2도는 검사용 거치 예시 각도이며 물리적인 닫힘 제한 각도가 아닙니다.
- 본체 두께를 나타내는 **폭15.5mm** 노트북 모사 상자가 양쪽 받침에 앉고 멈춤 기구와 겹치지 않는지 검사했습니다. 모사 상자는 지오메트리 확인용이며 실제 맥북 모서리 곡률·무게중심을 재현하지 않습니다.
- 몸체가 맞물리는 경로81개 위치, 주 축과 고정 캡은 각각41개 삽입 위치에서 부품 간 간섭을 검사합니다. 캡 내부 키가 원형 윤곽 밖으로 돌출하지 않는지와 축을 양방향으로 당겼을 때 고정 턱이 걸리는지도 기하학적으로 확인합니다. 물리적 삽입력/유지력을 이 검사로 입증하지 않습니다.
- 뒤쪽을 향하는 걸이 한 쌍의 고무줄 예시 경로를33자세에서 검사합니다. 동일한 경로 데이터를 렌더링에도 사용하며, 예시 굵기 기준의 몸체/축 간섭·바닥 여유와 몸체 밖으로 튀어나오는지 확인합니다. 원치 않는 아래 선반이 제거되고 걸이 축이+Y방향인지도 실제 솔리드로 검사합니다. 실제 고무줄의 단면과 변형은 실물 확인 대상입니다.
- 열린 상태에서 축 아래 턱의 맞닿는 면적은20mm²입니다. 더 벌리려는 -0.1도/-2도에서 턱이 겹쳐 회전을 막고, 닫히는 방향10.2도까지는 별도 멈춤 없이 움직이는지 검사합니다. 후자의 검사는 노트북이 없는 상태의 기하 확인입니다.
- 설계 계산상 축 높이는22.00→15.64mm, 위쪽 펠트 사이 폭은32.80→15.35mm입니다. 마지막 폭은 맥북 본체15.5mm보다 약0.15mm 작아 펠트가 조금 눌리는 구상입니다. 실제 압착량을 보장하는 값은 아닙니다.
- 회전할수록 고무줄 걸이 간 거리는 늘고 고무줄 토크는 벌림 방향입니다. 장력·마찰·지지대 자중을 포함한 힘의 균형, 반복 내구성, 고무줄 수명은 **실물 미확인**입니다.

조립 렌더링: `docs/evidence/assembly-open.png`, `assembly-loaded.png`. 주황 고무줄은 경로 예시입니다. 그림 자체가 실물 작동의 증거는 아닙니다.

하단 턱 확대: `docs/evidence/joint-detail-open.png`은 열린 상태의 맞닿음, `joint-detail-loaded.png`은 오므라든 상태의 분리를 보여 줍니다. 이 확대 그림에서는 턱을 보기 쉽도록 고무줄을 표시하지 않았습니다.

안쪽 걸이 확대: `docs/evidence/inside-open.png`, `inside-loaded.png`은 뒤쪽에서 하단 내부를 본 모습입니다. `hook-detail.png`는 실제 왼쪽 몸체만 표시해 넓어진 받침·목·머리의 연결을 볼 수 있는 확대 모습입니다. 전체 뷰의 주황색 고무줄은 배치 예시입니다.

원형 고정 캡 확대: `docs/evidence/retainer-installed.png`. 노출되는 막대·손잡이를 없애고 지름10mm의 원형 마감 캡 안쪽에 고정 키를 일체형으로 숨겼습니다. `key-detail.png`는 바깥에서 보이지 않는 내부 형상입니다. 렌더링은 캡을 몸체와 비슷한 색으로 표현했으며 같은 색 필라멘트로 출력하면 축 마개처럼 어울리는 구상입니다. 실제 유지력은 출력 후 확인합니다.

## 원본과 수정 이유

원본 몸체와 연결부는 `references/body-original.stl`, `references/connector-original.stl`에 해시를 유지해 보존했습니다. 원본은 STL의 Z축 방향으로 길게 이어지고, XY 단면에 지지대와 연결부 결합부가 있습니다. 원본 축별 길이는 각각 약54.632×173.499×200mm와68.500×13.500×40mm입니다. STL에 단위가 없으므로 mm 가정은 사용자 사진과 형상 비율을 근거로 합니다.

이번에는 원본을 깎아 완제품을 만들지 않고, **단단한 축과 고무줄 복원에 필요한 기하를 확인하는 별도 시험편**을 만들었습니다. 원본 지지대의 길이·곡면을 그대로 유지한 전체 모델은 실제 시험 결과를 받은 다음 계획에서 다룹니다.

## 재생성

이 환경에서 사용한 도구는 FreeCAD1.1.3, Blender5.2.1, Bambu Studio02.08.02.61입니다. FreeCAD의 OpenCascade 솔리드 커널로 형상을 만들고 STL·STEP·FCStd를 생성합니다.

```bash
bash scripts/freecad_python.sh cad/build_calibration.py
python3 scripts/check_geometry.py --target calibration
python3 scripts/slice_calibration.py --kit fit
python3 scripts/slice_calibration.py --kit mechanism
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/render_models.py
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/render_models.py -- --detail-only
```

FreeCAD 경로가 다르면 `FREECAD_ROOT`를 앱의 Resources 디렉터리로 지정합니다. 형상 파라미터는 `cad/parameters.json`, 생성 코드는 `cad/build_calibration.py`에 있습니다. `cad/calibration.FCStd`와 `calibration.step`은 출력 배치, `cad/mechanism-assembly.FCStd`는 주 축과 쐐기를 포함한 열린 조립 상태입니다.

CAD API 참고: [FreeCAD 공식 메시 생성 문서](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Mesh_FromPartShape.md).

## 출력 후 알려 줄 결과

아래 항목을 알려 주시면 전체 PLA 스탠드 계획에 반영합니다.

```text
사용 PLA / 노즐 / 레이어:
잘 맞는 링: 점1 / 점2 / 점3 / 모두 안 맞음
6mm 축의 회전: 뻑뻑함 / 적당함 / 헐거움
경첩 끝면의 서포트 거칠기와 앞뒤 간격·흔들림:
원형 고정 캡 끼움·분리: 들어가지 않음 / 적당함 / 쉽게 빠짐
하단 맞물림 턱이 벌림을 막는지:
가로부 뒷면 걸이에 고무줄이 잘 걸리는지:
고무줄을 걸었을 때 스스로 벌어지는지:
중앙을 눌렀을 때 모이고 놓으면 다시 벌어지는지:
바닥 걸림 / 축 이탈 / 기타 문제:
```

PETG 전환 시에는 같은 끼움 시험을 다시 해야 합니다. PLA에서 맞았다는 이유로 PETG 공차나 양산 적합성을 확정하지 않습니다.
